# java-fundamentals/02-strings
***
This folder will focus on Strings from Java.

It consists of the following java files:
***
    StringBasics.java
        Demonstrating String creation and working with Strings.
        Using some methods available in Strings.
        How some mutable Strings work.
        Showing String Tokenizer.

    TextIO.java
        Demonstrates the very basics of reading/writing from/to text files.

    BinaryIO.java
        Demonstrates reading/writing data from/to binary file.
        Demonstrates reading/writing objects from/to binary file.
